# وظيفتي — جلب تلقائي لإعلانات الوظيفة العمومية

## المحتويات
- `site/index.html` : الموقع (يقرأ `jobs.json`، وإن لم يوجد يعرض بيانات تجريبية).
- `scraper/scrape.py` : سكربت الجلب (يكتب `site/jobs.json` فقط، ولا ينسخ أي ملف PDF؛ زر القرار والترشح يفتحان الموقع الرسمي).
- `.github/workflows/update-site.yml` : يشغّل السكربت كل 3 ساعات وينشر الموقع.

## النشر (مرة واحدة)
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `wazifati`) وارفع كل محتويات هذا المجلد إليه (فرع `main`).
2. من **Settings → Pages** اختر **Source: GitHub Actions**.
3. من تبويب **Actions** اختر `update-site` ثم **Run workflow**.
4. بعد دقائق يظهر رابط الموقع في تبويب Pages. يتحدّث تلقائياً كل 3 ساعات.

## إن ظهرت الصفحة بالبيانات التجريبية أو فشل التشغيل
1. افتح تشغيل الـ workflow وانظر سجلّ خطوة **Fetch announcements**.
2. نزّل الملف المرفق `debug-html` (يحتوي `list_page1.html` و`detail_first.html`).
3. أرسل لي السجلّ وهذين الملفين لأضبط السكربت على بنية الصفحات الحقيقية.
   (السكربت لم يُختبر على الموقع الحي، لذلك قد يحتاج تعديلاً بسيطاً في أول تشغيل.)

## تشغيل محلي للتجربة
```
pip install -r scraper/requirements.txt
python scraper/scrape.py --out site/jobs.json --debug
python -m http.server -d site 8000   # ثم افتح http://localhost:8000
```

## ملاحظات
- السكربت يترك 1 ثانية بين الطلبات؛ لا تقلّلها.
- إن لم يجد أي إعلان يفشل التشغيل عمداً ويبقى الموقع السابق كما هو.
- راجع شروط استعمال البوابة قبل النشر العام.
